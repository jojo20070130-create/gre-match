等价词速配

  1. 配对点左边一个词，再点右边同义的词。75 秒配满 20 对通关。
  2. 计时第 6、13 对各 +8 秒，连对 3 次起每对 +1 秒，配错 −3 秒。
  3. 查词右键（手机长按）单词看英文释义。
  4. 背单词右键（手机长按）词组，先看整组词表：红 = 错过，绿 = 配对过，白 = 还没遇到。
  5. 收藏点 ☆ 收藏一对词，词表、查词弹窗、结算页都能收藏；「收藏夹」可以单独配对。
